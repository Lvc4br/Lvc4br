# Technical Art Toolkit — Blender + Python

> A practical toolkit for improving and automating common 3D production workflows in Blender.

## 🎯 Goal

This project is focused on the **Technical Art** side of 3D production: using Python to reduce repetitive work, validate scenes and create artist-facing utilities.

## Planned Modules

- **Scene Utilities** — organize collections and production data
- **Naming & Validation** — detect inconsistent object names and common scene issues
- **Material Utilities** — automate repetitive material setup
- **Procedural Tools** — generate controlled variations using parameters and seeds
- **Export Helpers** — prepare assets for consistent delivery

## 🧠 Technical Concepts

- Blender Python API (`bpy`)
- Operators and panels
- Procedural generation
- Deterministic randomization with seeds
- Scene and asset validation
- Automation of repetitive production tasks
- Artist-facing tool design
